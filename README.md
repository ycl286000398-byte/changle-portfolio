# changle.design

Public static export of Linna Yang / 杨常乐's portfolio.

GitHub Pages serves this repository's `main` branch from the root. Custom domain: `changle.design`.

This branch replaces the previous export with the current site. Assets load from the domain root (`/_next`, `/portrait`, `/works`, `/projects`). Old `/changle-portfolio/...` URLs redirect to the same path without that prefix.

Do not point the domain at the private Cursor app at `product-portfolio.apps.grok.bot`.
